## Code policy for this experiment

This directory contains an **independent implementation** for a local Ripple research
experiment. **No source files were copied** from the LILA repository. The method is a
simplified retrospective screening inspired by LILA’s pairwise-regression + CUSUM
identification ideas; it **does not** reproduce the paper’s reported results or
BattLeDIM competition scores.
